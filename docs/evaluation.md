## 1. 目的与范围

验证本地 NPC 的事实记忆、问题相关性、角色表现与 JSON 跨会话恢复。采用固定场景和人工评分，属于小规模原型观察，不代表完整游戏环境表现或稳定的模型性能。

- 操作系统：Windows / PowerShell，见原始终端记录。
- CPU、GPU、内存、Ollama 版本：历史记录未采集，不倒填为已确认数据。
- 模型：`qwen2.5:3b`；模型 digest 未记录。
- 角色文件：`characters/linzhou.md`；C 增加“对话行为边界”。
- 请求超时：180 秒；最大生成 token：512；历史窗口：最近 6 轮。
- 其他生成参数未显式设置，使用模型默认值；随机种子未固定。
- 各轮执行时的 Git commit、工作区差异和角色文件哈希未保存，不能以当前 HEAD 代替。

今后新增实验应在运行前记录日期、`git rev-parse HEAD`、`git status --short`、`ollama --version`、`ollama list`、配置及角色文件版本。

## 4. 固定对话场景

1. 我叫小雨，不喝酒，明天想去旧灯塔。
2. 给我推荐一种喝的吧。
3. 我刚才说想去哪里？
4. 我改主意了，不是明天，是今晚去。
5. 我什么时候出发？路上有什么要注意的？
6. （坐下来喝热水）这雨让我有点担心，你能陪我聊聊吗？
7. 我叫什么？我喝酒吗？
8. 我去旧灯塔的计划是什么？

第 8 轮后退出，用同一玩家 ID 重启，再问第 9 问：你还记得我叫什么吗？

另用全新玩家 ID 问第 10 问：你知道我叫什么吗？

原始记录显示同一 ID 重启后使用相同存档，不同 ID 使用不同存档。未保存各组开始前存档不存在的证明，因此初始空白状态依据测试操作约定，不视为独立审计结论。

第 9 问可能利用第 7 问中再次出现的姓名，不能证明超出窗口的长期记忆。

## 5. 评分规则

| 检查点 | 对应问题 | 通过标准 |
| --- | --- | --- |
| 饮品偏好 | 2 | 尊重不喝酒的偏好，推荐无酒精饮品 |
| 目的地 | 3 | 正确回答旧灯塔 |
| 信息更正 | 5 | 采用今晚，不沿用明天 |
| 问题相关性 | 6 | 回应担忧或陪聊请求，没有只复述角色背景 |
| 姓名与偏好 | 7 | 同时回答小雨、不喝酒 |
| 计划记忆 | 8 | 同时回答今晚、旧灯塔 |
| 重启恢复 | 9 | 重启后回答小雨 |
| 玩家隔离 | 10 | 明确承认没有名字信息，不猜测为小雨 |

满足记 1，否则记 0。调用失败记 E，不计为通过，并另报失败次数。只评指定轮次，后续答对不补改先前分数。

“重复介绍轮数”仅统计第 2—8 轮中无必要的自我介绍，不代表所有类型的重复。语气、世界观依据和自行同行另作定性分析，不事后加入原有评分分母。

## 7. 失败分析与局部改善

| 观察 | 原始证据 | 解读 |
| --- | --- | --- |
| 玩家与 NPC 身份混淆 | A-1 第 7 问回答“我叫林舟”；B-1 新玩家问题也回答林舟 | 保存历史正确不保证模型正确归属事实 |
| 偏好主体混淆 | B-2 第 7 问“我们这不喝酒” | 未正确回答玩家偏好；当前存档仅保存对话原文，没有证据表明程序修改了结构化偏好字段 |
| 计划召回不完整 | 四组第 8 问均未同时回答今晚、旧灯塔 | 共性未解决问题，后续轮次答对不补分 |
| 无依据背景补充 | A-1 的发光古树；B-2 的当前涨潮、野兽 | 不能因模型自己说过就认定是世界事实 |
| 过度亲近与自行同行 | B-2“有你在身边，就不怕了”“我们去旧灯塔” | 偏离初识旅人的克制语气与行动约定 |
| C 的局部改善 | C-1 未见上述亲密依赖、偏好主体混淆和同行承诺；新玩家明确回答不知道 | 仅是当前样本观察，不宣称错误已经消除 |
| C 的剩余问题 | 第 4 问再问目的地；第 8 问转向姜茶；“不太适合无人通行” | 仍有信息接续、模板化推荐和表达依据问题 |

评分由人工依据规则作出，未进行盲评或多评审一致性检验。失败原因尚未通过控制实验确认，不直接归因于模型规模或接口方式。

## 8. 阶段性结论

目前归档早期记录一组（5/8）、B 两组（均 6/8）、C 一组（7/8）。C 本次表现出更克制的语气、较明确的偏好归属和新玩家回答；计划完整召回仍未解决。

样本量小、样本数不均、早期接口归属未核验且环境信息不完整，因此只能报告局部改善迹象，不能声称稳定提升或 A/B 因果效果。

另有 5 项单元测试通过，验证上下文构造、持久化、隔离和失败保护。单元测试使用替身回复，与真实模型人工评测分开报告。GitHub Actions 只运行单元测试，不下载模型，也不自动评判 NPC 对话质量。
